# Arsellia Portfolio

Portfolio personnel de développeur Web Full Stack, conçu avec une forte identité visuelle et des animations interactives.

## 🌐 Site officiel

🚀 **Découvrez mon portfolio :**

👉 [arsellor.github.io/PORTFOLIO](https://arsellor.github.io/PORTFOLIO/)

## ✨ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Canvas API
- Vidéo et animations scroll-driven

## 📁 Structure actuelle

```text
Arsellia-Portfolio/
├── assets/          # Images, vidéos, icônes et animations
├── css/             # Styles globaux, composants et pages
├── js/              # Scripts globaux et scripts de pages
├── projects/        # Pages de détail des projets
├── documents/       # Documents publics (CV)
├── docs/            # Documentation technique et maintenance
├── index.html       # Accueil

├── contact.html     # Contact
```

> Le dossier `_archive/` a volontairement été retiré de cette version GitHub afin d'éviter de publier les anciennes versions et fichiers de travail.

## 🚀 Lancer le projet

Le projet est statique. Ouvrez-le avec un serveur local, par exemple VS Code + Live Server.

Consultez [`docs/GITHUB_CHECKLIST.md`](docs/GITHUB_CHECKLIST.md) et [`docs/CODE_MAINTENANCE.md`](docs/CODE_MAINTENANCE.md).

## 🎯 Objectif de maintenance

La prochaine étape recommandée est de centraliser le header/navbar et de migrer progressivement les styles vers :

- `css/base/`
- `css/components/`
- `css/pages/`
- `js/components/`
- `js/pages/`

Cela évitera les différences de taille et de comportement entre les pages.
