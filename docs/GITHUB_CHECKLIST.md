# Checklist avant publication sur GitHub

## Code
- [ ] Aucun `console.log()` inutile
- [ ] Aucun lien `href="#"` laissé par erreur
- [ ] Aucun chemin local Windows (`C:\Users\...`)
- [ ] Aucun code mort évident
- [ ] Les fichiers ont des noms cohérents

## Header / Navbar
- [ ] Même structure HTML sur toutes les pages
- [ ] Même fichier CSS principal
- [ ] Même hauteur sur toutes les pages
- [ ] Icônes dans des boîtes de dimensions fixes
- [ ] Test mobile / tablette / desktop

## Performance
- [ ] Images compressées
- [ ] Vidéos optimisées
- [ ] Animations chargées intelligemment
- [ ] Pas d'anciens fichiers dans le repository

## GitHub
- [ ] `.gitignore` présent
- [ ] `README.md` présent
- [ ] Repository sans `_archive/`
- [ ] Aucun secret ou fichier `.env`
