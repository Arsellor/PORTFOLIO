Projet interactif · Jeu natif

Snaketris

Un jeu C++ / SDL2 qui combine des mécaniques de Snake et de Tetris : le serpent récupère des fruits colorés et alimente son score.

Technologies

  • C++
  • SDL2
  • Makefile
  • Programmation modulaire
  • SAÉ

Principes du jeu

Snake : le serpent grandit lorsqu’il mange un fruit, le score augmente et un nouvel élément apparaît.

Tetris : quand trois anneaux consécutifs ont la même couleur, celui du milieu disparaît.

Objectif : pratiquer la programmation modulaire en C++ avec la bibliothèque SDL2.

Code source et instructions

La version native se pilote au clavier. Sur téléphone, cette page permet de regarder la vidéo ; le dépôt GitHub contient le code source et les instructions pour lancer le jeu.

Commandes du jeu natif

↑ ↓ ← → Déplacer le serpent
Espace Pause / reprendre
S Sauvegarder la partie
Q / Échap Quitter le jeu

Règles principales

  • Le serpent perd s'il touche le bord du plateau.
  • Le serpent perd s'il touche son propre corps.
  • Les fruits rouge, vert et bleu font évoluer la partie.
  • L'étoile peut supprimer un triplet d'anneaux identiques.
